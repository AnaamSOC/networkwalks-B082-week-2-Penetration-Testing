# Cybersecurity Practical – Network Footprinting & Zenmap Scanning

## Overview

This project documents two practical cybersecurity modules completed using Kali Linux and Zenmap. The activities focused on network reconnaissance, host discovery, information gathering, and network scanning.

The project demonstrates practical exposure to commonly used cybersecurity reconnaissance and network-scanning techniques in a controlled lab environment.

---

## Modules Completed

### W2-PM1 — Footprinting with Multiple Kali Tools

This module focused on gathering information about a target environment using multiple Kali Linux reconnaissance tools.

#### Objectives

- Perform basic network reconnaissance
- Gather information about a target
- Identify available network information
- Understand the purpose of different footprinting tools
- Document reconnaissance results

#### Tools Used

- Kali Linux
- Nmap
- WHOIS
- DNS/reconnaissance utilities
- Other Kali Linux footprinting tools used during the practical

#### Key Learning

The practical helped demonstrate how cybersecurity professionals perform information gathering during the reconnaissance phase of a security assessment.

---

### W2-PM5 — Zenmap Network Scanning

This module focused on network scanning using Zenmap, the graphical interface for Nmap.

#### Objectives

- Discover hosts on a network
- Perform network scanning
- Identify open ports and services
- Analyse scan results
- Understand Zenmap's graphical representation of scan data

#### Tool Used

- Zenmap / Nmap
- Kali Linux

#### Scan Performed

A network scan was performed against the assigned lab network/host.

The scan results were analysed to identify available hosts, ports, and services.

## Methodology

### 1. Network Reconnaissance

Initial reconnaissance was performed using Kali Linux tools to gather information about the target environment.

### 2. Host Discovery

Network discovery techniques were used to identify active hosts within the assigned environment.

### 3. Network Scanning

Zenmap was used to perform network scanning and analyse the discovered host.

### 4. Result Analysis

The scan results were reviewed to identify:

- Active hosts
- Open ports
- Detected services
- Network information
- Other relevant scan results

### 5. Documentation

Screenshots and observations were documented as part of the practical report.
